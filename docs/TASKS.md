# 프로젝트 작업 목록 (TASKS)

본 문서는 1인 개발 환경의 리소스 절약과 "무신사 스크래핑 데이터 위주의 빠른 탐색, 30초 내 VTON 완료"라는 명확한 타겟에 맞춰 설계/인프라스트럭처 테스트를 선행하는 P0, P1, P2 목록입니다. 

*(추천 이유 생성 및 날씨 기반 추천 기능은 제외됨)*

## [P0] 초기 기반 스캐폴딩 및 데이터/VTON 기술 검증 (PoC 확립)
프론트-백 간의 연동 및 외부 무거운 GPU 모델의 통신 한계점 30초 타켓을 조기 검증합니다.

* [ ] **T-001:** 프론트엔드-백엔드 초기 최소 스캐폴딩 생성 연결 (React + FastAPI 통신 환경 구성)
* [ ] **T-002:** RunPod 컨테이너 셋업 및 Hugging Face `fashn/fashn-vton-1.5` 인퍼런스 외부 API 통신 테스트 (실제 피팅 리소스 생성까지 30초 내외 소요시간/병목 현상 1차 검증)
* [ ] **T-003:** 무신사 상의/하의 중심의 상품 정보 및 구매자 리뷰 정보를 획득하는 별도의 스크래퍼(스크립트) 작성

## [P1] 핵심 엔진 (LangGraph State & Hybrid Search) 기반 구축
T-003에서 획득한 데이터를 바탕으로 빠르고 다채로운 검색망과 평가 로직들을 엮어냅니다.

* [ ] **T-101:** 로컬 환경에 스크래핑 데이터를 임베딩하고 ChromaDB 상에 인덱싱 파이프라인 구성
* [ ] **T-102:** LangGraph 핵심 도메인 State 객체 및 뼈대 설계 수립 
* [ ] **T-103:** 자연어 질의가 왔을 때 구조화(Query Parsing) 기능 개발
* [ ] **T-104:** 파싱된 구조 및 Dense 벡터 쌍을 이용한 ChromaDB Hybrid Search 로직 통합
* [ ] **T-105:** 단순 검색된 대량의 후보를 두고 리뷰 내용 요약 기반 선호도 점수로 우선순위를 바꾸는 Reranking 처리 노드 구현
* [ ] **T-106:** FastAPI 서버를 통해 프론트엔드의 화면 단에 검색 결과 UI 빠르게 렌더링하기 (수 초 이내 검색 응답 체계)

## [P2] VTON 데이터 전처리 고도화 및 최종 피팅 
실제 피팅을 위한 준비 동작을 똑똑하게 만들고, 체형 데이터 반영 및 개인 옷장 관리를 더합니다.

* [ ] **T-201:** VTON 입력 이미지 모델 사진 자동 선별(Scoring) 로직 개발 (수많은 썸네일/리뷰 컷 중 조명과 전신 자세 기준 최고 합격점을 찾는 노드)
* [ ] **T-202:** 체형 프로필 입력을 필터 메타데이터 매핑 및 VTON 사이즈/포지션 보정 옵션으로 통합
* [ ] **T-203:** 사용자가 직접 자신의 상/하의 개인 의류 이미지를 업로드하고, LangGraph 그래프에서 데이터 상태(Local 옷장 vs Web 스토리지 옷장)를 제어/관리하는 기능 구성
* [ ] **T-204:** RunPod VTON API를 오케스트레이션 플로우에 본격 연동 및 UI와 턴키 연결 완성
