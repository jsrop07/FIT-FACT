# Fit & Fact 프로젝트 개요 (Project Overview)

## 1. 프로젝트 개요
자연어 기반 패션 검색과 사용자 사진 기반 가상 피팅을 결합한 멀티모달 AI 패션 탐색 시스템입니다.
1인(Solo) 개발 환경에 최적화하여, 설계부터 단계적으로 구현하며 초기 데이터는 무신사 상의/하의 위주로 스크래핑을 진행하여 구축하고 핵심 피팅 기능 검증에 집중합니다.

## 2. 주요 제약 조건
* **1인 개발 (Solo Developer):** 복잡성을 낮추기 위해 기초 설계 및 최소 기능 단위로 단계적 구현 (추천 이유 생성, 날씨 기반 추천 기능은 현재 스코프에서 제외)
* **초기 데이터 포커스:** 무신사 상의/하의 상품 중심의 크롤링 데이터셋 확보 및 활용
* **성능 및 레이턴시 목표:** 패션 검색은 빠르게(수 초 이내), VTON(가상 피팅) 연산은 30초 이내 완료를 목표로 함
* **하드웨어 및 인프라 구성:** 로컬(MX450 등 보조 엔트리급 GPU)에서는 사실상 가벼운 오케스트레이션과 인퍼런스만 처리. VTON과 같은 무거운 모델 학습 및 실행은 RunPod 등의 클라우드 환경에 위임하여 하이브리드 형태로 구성. VTON 모델은 `fashn/fashn-vton-1.5` 적용 예정.

## 3. 핵심 기능
1. **자연어 기반 패션 검색:** 일상 언어를 질의(Query) 형태로 구조화(Parsing)하여 의도 파악
2. **벡터 DB 기반 의미 검색:** Dense 탐색 및 메타데이터 필터를 활용한 고속 검색
3. **구매자 평가 요약 기반 재정렬:** 추출된 리뷰 정보를 바탕으로 상품 랭킹(Reranking)을 재조정
4. **상의/하의 선택 및 조합:** 검색된 무신사 데이터에서 상의와 하의 아이템 믹스 앤 매치
5. **사용자 사진 기반 가상 조합 피팅:** 타겟 옷과 사용자 사진을 VTON 모델을 통해 합성
6. **체형 프로필 반영:** 신체 데이터를 메타데이터로 기반으로 결과물을 보정 및 필터링
7. **LangGraph 기반 에이전트 오케스트레이션:** 복잡하게 연결된 탐색-평가-합성의 과정들을 상태(State) 기반의 그래프 파이프라인으로 일관성 있게 제어
8. **사용자 보유 의류 업로드 및 피팅:** 본인 소유의 옷과 새롭게 추천된 옷을 교차 매칭

## 4. 기술적 딥 포인트 (Technical Deep Points)
* **질의 구조화 (Query Parsing):** 자연어 문장을 색상, 스타일, 품목 등의 메타데이터 및 속성으로 정교하게 분리 파싱해 검색 품질 향상
* **Hybrid Search (Dense + Metadata Filtering):** ChromaDB를 활용해 단순 임베딩 벡터 간 유사도 탐색뿐 아니라, 파싱된 속성에 기반한 강력한 필터링 연산을 병합하여 정확도 높은 의류 탐색
* **VTON 입력 이미지 자동 선별 스코어링:** 가상 피팅 모델 성능 최적화를 위해, 다수의 썸네일/포즈 사진 중 어떤 사진(신체 정면, 조명 상태 등)이 피팅의 타겟으로 가장 적합한지 내부적으로 판단/채점하는 논리 구현
* **LangGraph 기반 상태 오케스트레이션 (State Orchestration):** 사용자의 최초 질의 상태(State)에서 시작해 쿼리 파싱, 하이브리드 검색, 스코어링, VTON 대기 등 각 태스크 노드 간 메모리와 상태 전이를 안정적으로 유지 및 관리

## 5. 초기 기술 스택 요약
* **Frontend:** React (SPA)
* **Backend:** FastAPI (로컬 메인 서버 및 LangGraph 진입점)
* **Vector DB:** ChromaDB (로컬 환경 기반 벡터스토어 연동)
* **AI & Infrastructure:** LangGraph(오케스트레이션), RunPod / Hugging Face API (`fashn-vton-1.5` 서빙 및 연산 증폭)
